# 浜名湖うなぎ紹介サイト

観光客向けに浜名湖うなぎの魅力を伝える、和モダンテイストの静的紹介サイト。

## 概要

- **目的**: 浜名湖うなぎの歴史・特徴・お店・料理・アクセス情報を観光客に提供
- **技術**: HTML / CSS / Vanilla JS（ビルドツール不要）
- **デザイン**: 和モダン（朱赤×深緑×生成り、Noto Serif JP 見出し）
- **対応**: レスポンシブデザイン（PC・スマートフォン）

## ページ構成

| ファイル | 内容 |
|---|---|
| `index.html` | トップ（ヒーロー・サイト概要・ナビカード・おすすめの一品） |
| `history.html` | 歴史・特徴（タイムライン年表・美味しさの3要素） |
| `shops.html` | お店紹介（5軒：老舗・湖畔・炭火・創作・テイクアウト） |
| `dishes.html` | 料理紹介（蒲焼・白焼き・うな丼・ひつまぶし＋食べ比べ表） |
| `access.html` | アクセス（交通手段・周辺マップ・観光名所・Q&A） |
| `style.css` | 共通スタイル |
| `main.js` | ナビ・Q&Aアコーディオン・トップへ戻るボタン |

## デザインの特徴

- **カラー**: 朱赤 `#a8321d` / 深緑 `#2d4a3a` / 生成り `#f5f0e6` / 墨色 `#1a1a1a`
- **タイポグラフィ**: Noto Serif JP（見出し） + Noto Sans JP（本文）
- **装飾**: 縦書きアクセント、和風罫線、グラデーション背景
- **画像**: 外部画像に依存せず、CSS グラデーションと漢字一文字の大型プレースホルダで雰囲気を演出（完全オフライン対応）

## 既存 `kklab-kiro-unagi-site` との違い

本サイトは以下の方針でフルスクラッチから作成しています：

| 項目 | 本サイト (kklab-minmax-examples) | 既存サイト (kklab-kiro-unagi-site) |
|---|---|---|
| デザイン | 和モダン（朱赤×深緑） | シンプル・洗練（ベージュ×ゴールド） |
| タイポ | 明朝体（Serif）中心 | ゴシック体（Sans）中心 |
| ヒーロー | 縦書きアクセント・漢字一文字 | 英語ラベル付き |
| 歴史ページ | タイムライン形式 | 時系列ブロック |
| 料理ページ | 2x2 グリッド＋食べ比べ表 | 画像+テキスト交互 |
| アクセスマップ | SVG 風プレースホルダ＋ピン | Google Maps iframe |
| Q&A | あり（アコーディオン） | なし |

## 注意事項

- 本サイトの内容は説明用のサンプルです。掲載されている店舗名は架空のものです。
- 歴史的事実については一般に広く知られている情報に基づきつつ、断定を避けた表現を一部使用しています。
